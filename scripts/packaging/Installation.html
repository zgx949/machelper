machelper

安装与首次使用 · Installation & first launch
macOS 27.2+

01拖入“应用程序” / Install

machelper.app → Applications

将 App 拖入“应用程序”。ZIP 用户先解压再移动。随后从“应用程序”打开 machelper；不要直接从 DMG 运行。复制完成后可以推出 DMG。

Drag the app to Applications. For a ZIP, extract it first. Launch the copy in Applications, then eject the DMG.

02查看主界面并授权 / Review and allow access

默认启动后先显示主界面的通用页，展示权限与功能状态。打开侧栏的设置引导可查看安装位置、授权步骤和功能检查；已有权限时也能查看。

点击授权按钮，打开 系统设置 → 隐私与安全性 → 辅助功能，开启 machelper 开关。未列出时点 ＋ 添加 /Applications/machelper.app。

该权限用于反转滚动、移动窗口、键盘滚动和自动粘贴；剪贴板历史仍可在未授权时记录和搜索。App 每秒检查权限，授权后等待中的插件自动启动，窗口保留供你检查结果。

The main window opens to General, with permission and feature status. Setup Guide in the sidebar remains available after authorization. Enable System Settings → Privacy & Security → Accessibility → machelper. Use ＋ to add the app from Applications if missing. The app checks access every second and starts waiting plugins automatically; the window stays open for review. Accessibility enables scroll reversal, window layouts, keyboard scrolling and automatic paste. Clipboard history can still record and search without it.

打开辅助功能设置 / Open Accessibility Settings

03检查功能并收起 / Check and continue

在长网页中试滚动：默认只反转鼠标，触控板保持原样。在 菜单栏图标 → 设置… → 滚动方向 检查插件是否“运行中”。

点击收起并在菜单栏运行或关闭窗口，已开启的功能继续运行。machelper 常驻屏幕顶部菜单栏，不显示 Dock 图标。菜单中的打开 machelper…、设置…和安装与授权引导…都会回到同一个主窗口。

Scroll a long webpage. Mouse reversal is on by default; trackpad reversal is off. Check that Scroll Direction is running in Settings. Choose Continue in Menu Bar or close the window to keep enabled features running. The app has no Dock icon. Open machelper…, Settings… and Setup Guide… in its menu reopen the same main window.

04设置启动行为 / Startup preferences

在通用 → 启动中按需开启开机自启。状态来自 macOS；如提示需要批准，点击打开登录项…完成。注册失败时此处会显示错误。

启动时显示主界面默认开启。关闭后直接驻留菜单栏；缺少辅助功能权限或有功能启动失败时仍会显示窗口。再次打开 App 也可显示主窗口。

Optionally enable Launch at Login under General → Startup. Its state comes from macOS. If approval is needed, choose Open Login Items…; registration errors appear here. Show Main Window at Launch is on by default. Turn it off to start in the menu bar unless Accessibility is missing or a feature fails to start. Opening the app again also shows its window.

需要帮助？ / Need help?

授权后仍未生效：确认运行的是“应用程序”中的版本。在辅助功能列表中关闭再开启开关。更新后仍无效时，退出 App，移除旧条目，再添加当前 App 并重新打开。插件出错时可在设置中重试。

运行中但方向没变：检查反转开关，暂停其他滚动工具。发送手势或惯性阶段的 Magic Mouse 等设备使用“反转触控板”；无阶段的高精度鼠标使用“反转鼠标”。

If permission is not recognized, toggle access off and on. After an update, quit the app, remove its old Accessibility entry, add the current copy, then reopen it. Retry failed plugins in Settings. Check reversal switches and pause other scroll tools; Magic Mouse gestures use the trackpad setting; high-resolution wheels without gesture phases use the mouse setting.

首次打开被拦截：确认下载来自本项目 Release 后，按 Apple 的说明 / Apple's instructions 在“隐私与安全性”中选择“仍要打开 / Open Anyway”。
